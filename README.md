# Netflix Data Analysis

## Project Overview

This project analyzes Netflix movies and TV shows using Python and Pandas.

## Objectives

* Handle missing values in the dataset.
* Compare Movies and TV Shows in the United States.
* Analyze movie ratings.

## Dataset

* Dataset: Netflix Titles
* Total Records: 8,807
* Total Columns: 12
* Format: CSV

## Tools and Technologies

* Python
* Pandas
* Jupyter Notebook
* Google Colab

## Project Tasks

1. Load the Netflix dataset.
2. Check and handle missing values using `dropna()`.
3. Identify whether Movies or TV Shows are more numerous in the United States.
4. Analyze movie rating frequencies.

## Key Findings

* Missing values were handled.
* Movies are more numerous than TV Shows in the United States in this dataset.
* Movie ratings were analyzed using frequency counts because ratings are categorical.

## Files Included

* `Netflix_Assignment.ipynb` – Python analysis notebook.
* `netflix_titles.csv` – Dataset.
* `README.md` – Project documentation.

## Conclusion

This project demonstrates basic data cleaning, filtering, and analysis using Python and Pandas.
